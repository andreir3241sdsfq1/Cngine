2. COMPILING (WINDOWS)
=========================================================================

Requirements:
  - w64devkit (MinGW-w64) or equivalent GCC for Windows
    Download: https://github.com/skeeto/w64devkit/releases
  - gcc must be in PATH

Steps:
  1. Open a command prompt in the Cngine_output/ folder
  2. Run:  cmp.bat
  3. On success, game.exe will be created
  4. Copy SDL2.dll next to game.exe
     (SDL2.dll can be obtained from https://github.com/libsdl-org/SDL/releases)

What cmp.bat does:
  Step 1 — compiles Lua 5.4 (all .c files from lua/ directory)
  Step 2 — compiles engine modules (engine_math, physik, render, core,
            hitboxes, audio, postfx_config, scripts)
  Step 3 — compiles game.c
  Step 4 — links everything into game.exe with SDL2

Compiler flags used:
  -m64         64-bit build
  -I.          current directory (engine/) in include paths
  -Ilua        Lua headers
  -Isdl        SDL2 headers (engine/sdl/)
  -DLUA_USE_WINDOWS  required for Lua on Windows

3. QUICK START — MINIMAL GAME
=========================================================================

  // game.c
  #include "engine/core.h"
  #include "engine/render.h"

  typedef struct { float x, y; } MyData;

  void my_init(GameState* gs) {
      MyData* d = (MyData*)gs->user_data;
      d->x = gs->window_width / 2.0f;
      d->y = gs->window_height / 2.0f;
  }

  void my_update(GameState* gs, float dt) {
      MyData* d = (MyData*)gs->user_data;
      if (input_key(&gs->input, SDL_SCANCODE_RIGHT)) d->x += 100 * dt;
      if (input_key(&gs->input, SDL_SCANCODE_LEFT))  d->x -= 100 * dt;
      if (input_key(&gs->input, SDL_SCANCODE_ESCAPE)) game_quit(gs);
  }

  void my_render(GameState* gs, Renderer* r) {
      MyData* d = (MyData*)gs->user_data;
      renderer_draw_circle(r, vec2(d->x, d->y), 10, COLOR_WHITE, true);
      renderer_draw_text(r, "Hello Cngine!", vec2(4, 4), COLOR_YELLOW, 1.0f);
  }

  int main(void) {
      MyData data = {0};
      GameState* gs = game_create("My Game", 640, 400, 60);
      gs->user_data = &data;
      gs->callbacks.init   = my_init;
      gs->callbacks.update = my_update;
      gs->callbacks.render = my_render;
      game_run(gs);
      game_destroy(gs);
      return 0;
  }

5. MODULE: core.h
=========================================================================

GameState* game_create(title, width, height, target_fps)
  Creates a window and all engine subsystems.
  Returns a pointer to GameState.

void game_run(GameState* gs)
  Starts the game loop. Blocks until exit.
  Calls callbacks in order: init → update → render → cleanup.

void game_destroy(GameState* gs)
  Frees all resources.

CALLBACKS (set via gs->callbacks):
  void (*init)(GameState*)              called once before the loop
  void (*update)(GameState*, float dt)  every frame, dt in seconds
  void (*render)(GameState*, Renderer*) every frame after update
  void (*handle_event)(GameState*, SDL_Event*)  raw SDL events
  void (*cleanup)(GameState*)           called on exit

GameState FIELDS:
  gs->renderer        Renderer*       renderer
  gs->physics_world   PhysicsWorld*   physics world
  gs->input           Input           input state
  gs->window_width    int
  gs->window_height   int
  gs->running         bool
  gs->paused          bool
  gs->time_scale      float           1.0 = normal speed
  gs->delta_time      float
  gs->elapsed_time    float
  gs->fps             int
  gs->user_data       void*           your game data

CONTROL:
  game_quit(gs)                    exit
  game_pause(gs)                   pause
  game_resume(gs)                  resume
  game_set_time_scale(gs, scale)   slow motion / fast forward
  game_get_delta_time(gs)          → float
  game_get_elapsed(gs)             → float
  game_get_fps(gs)                 → int
  game_mouse_world(gs)             → Vec2 (mouse in world coords)

INPUT (via gs->input):
  input_key(inp, SDL_SCANCODE_*)         key held
  input_key_pressed(inp, scancode)       pressed this frame
  input_key_released(inp, scancode)      released this frame
  input_mouse_btn(inp, button)           mouse button (0,1,2)
  input_mouse_pressed(inp, button)       pressed this frame
  input_mouse_pos(inp)                   → Vec2

8. MODULE: hitboxes.h
=========================================================================

The hitbox system is independent from physics — it is used for game logic
(attacks, pickup zones, detection). Supports AABB, Circle, OBB, Capsule,
Polygon, and Composite hitboxes.

CREATING HITBOXES:
  hb_create_aabb(half_w, half_h)       → Hitbox*
  hb_create_circle(radius)             → Hitbox*
  hb_create_obb(half_w, half_h)        → Hitbox*
  hb_create_capsule(radius, half_len)  → Hitbox*
  hb_create_polygon(verts, count)      → Hitbox*
  hb_create_composite()                → Hitbox* (container)
  hb_composite_add(parent, child)
  hb_destroy(hb)
  hb_scale(hb, sx, sy)

Hitbox fields:
  hb->offset       Vec2    offset from owner
  hb->rotation     float   local rotation (radians)
  hb->layer        uint16  collision layer
  hb->mask         uint16  collision mask (which layers it detects)
  hb->active       bool
  hb->is_trigger   bool    detection only, no physics response
  hb->owner        void*   pointer to your object
  hb->id           int     user ID
  hb->on_collision          callback on collision

  hb_world_center(hb, world_pos, world_rot)  → Vec2

  bool hb_contains_point(hb, world_pos, world_rot, point)

HitResult fields:

13. FREQUENTLY ASKED QUESTIONS
=========================================================================

Q: Why is the screen so small (320×200)?
A: The engine uses a pixel buffer for a retro aesthetic.
   It scales up to fill the window automatically.
   To change resolution: add to cmp.bat before compiling:
   -DPB_W=640 -DPB_H=360 (or any other size).

Q: How do I add a sound?
A: Only WAV format is supported. Use audio_load() from C or audio.load() from Lua.

Q: Where do I get SDL2.dll?
A: Download SDL2-2.x.x-win32-x64.zip from github.com/libsdl-org/SDL/releases
   and place SDL2.dll next to game.exe.

Q: How do world coordinates work?
A: World coordinates = pixel coordinates in the 320×200 buffer.
   The camera translates/scales the view. Use renderer_screen_to_world()
   to convert mouse position to world space.

Q: How do I enable Lua hot-reloading?
A: Call scripts_watch(sm, idx, true) then scripts_check_watches(sm, dt) every frame.

Q: What are the object limits?
A: Physics particles — dynamic array, no hard limit.
   HitboxManager — up to 1024 hitboxes (HBM_MAX).
   Lights — up to 32 (MAX_LIGHTS).
   Force fields — up to 16. Trigger zones — up to 16.
   Audio channels — up to 32 (AUDIO_MAX_CHANNELS).
   Loaded sounds — up to 128 (AUDIO_MAX_SOUNDS).

Q: What SDL2 version is required?
A: SDL2 2.0.x (2.0.18 or later recommended).

Q: Can I change the buffer resolution per-platform?
A: Yes. In cmp.bat add: -DPB_W=640 -DPB_H=480
   Or define them in a header before including render.h.
