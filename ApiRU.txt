2. КОМПИЛЯЦИЯ (WINDOWS)
=========================================================================

Требования:
  - w64devkit (MinGW-w64) или аналогичный GCC для Windows
    Скачать: https://github.com/skeeto/w64devkit/releases
  - Путь к gcc должен быть в PATH

Шаги:
  1. Откройте командную строку в папке Cngine_output/
  2. Запустите:  cmp.bat
  3. При успехе появится game.exe
  4. Скопируйте SDL2.dll рядом с game.exe
     (SDL2.dll можно взять с https://github.com/libsdl-org/SDL/releases)

Что делает cmp.bat:
  Шаг 1 — компилирует Lua 5.4 (все .c из папки lua/)
  Шаг 2 — компилирует модули движка (engine_math, physik, render, core,
           hitboxes, audio, postfx_config, scripts)
  Шаг 3 — компилирует game.c
  Шаг 4 — линкует всё в game.exe с SDL2

Флаги компилятора:
  -m64         64-битная сборка
  -I.          текущая папка (engine/) в include-путях
  -Ilua        заголовки Lua
  -Isdl        заголовки SDL2 (engine/sdl/)
  -DLUA_USE_WINDOWS  нужно для Lua на Windows

3. БЫСТРЫЙ СТАРТ — МИНИМАЛЬНАЯ ИГРА
=========================================================================

  // game.c
  #include "engine/core.h"
  #include "engine/render.h"

  typedef struct { float x, y; } MyData;

  void my_init(GameState* gs) {
      MyData* d = (MyData*)gs->user_data;
      d->x = gs->window_width / 2.0f;
      d->y = gs->window_height / 2.0f;
  }

  void my_update(GameState* gs, float dt) {
      MyData* d = (MyData*)gs->user_data;
      if (input_key(&gs->input, SDL_SCANCODE_RIGHT)) d->x += 100 * dt;
      if (input_key(&gs->input, SDL_SCANCODE_LEFT))  d->x -= 100 * dt;
      if (input_key(&gs->input, SDL_SCANCODE_ESCAPE)) game_quit(gs);
  }

  void my_render(GameState* gs, Renderer* r) {
      MyData* d = (MyData*)gs->user_data;
      renderer_draw_circle(r, vec2(d->x, d->y), 10, COLOR_WHITE, true);
      renderer_draw_text(r, "Hello Cngine!", vec2(4, 4), COLOR_YELLOW, 1.0f);
  }

  int main(void) {
      MyData data = {0};
      GameState* gs = game_create("My Game", 640, 400, 60);
      gs->user_data = &data;
      gs->callbacks.init   = my_init;
      gs->callbacks.update = my_update;
      gs->callbacks.render = my_render;
      game_run(gs);
      game_destroy(gs);
      return 0;
  }

5. МОДУЛЬ: core.h
=========================================================================

GameState* game_create(title, width, height, target_fps)
  Создаёт окно и все подсистемы движка.
  Возвращает указатель на GameState.

void game_run(GameState* gs)
  Запускает игровой цикл. Блокирует до выхода.
  Вызывает callbacks: init → update → render → cleanup.

void game_destroy(GameState* gs)
  Освобождает все ресурсы.

CALLBACKS (задаются в gs->callbacks):
  void (*init)(GameState*)              вызывается один раз до цикла
  void (*update)(GameState*, float dt)  каждый кадр, dt в секундах
  void (*render)(GameState*, Renderer*) каждый кадр после update
  void (*handle_event)(GameState*, SDL_Event*)  SDL-события
  void (*cleanup)(GameState*)           при выходе

ПОЛЯ GameState:
  gs->renderer        Renderer*       рендерер
  gs->physics_world   PhysicsWorld*   физический мир
  gs->input           Input           состояние ввода
  gs->window_width    int
  gs->window_height   int
  gs->running         bool
  gs->paused          bool
  gs->time_scale      float           1.0 = норма
  gs->delta_time      float
  gs->elapsed_time    float
  gs->fps             int
  gs->user_data       void*           ваши данные

УПРАВЛЕНИЕ:
  game_quit(gs)                    завершить
  game_pause(gs)                   пауза
  game_resume(gs)                  снять паузу
  game_set_time_scale(gs, scale)   замедление/ускорение
  game_get_delta_time(gs)          → float
  game_get_elapsed(gs)             → float
  game_get_fps(gs)                 → int
  game_mouse_world(gs)             → Vec2 (мировые координаты мыши)

INPUT (через gs->input):
  input_key(inp, SDL_SCANCODE_*)         зажата клавиша
  input_key_pressed(inp, scancode)       нажата в этом кадре
  input_key_released(inp, scancode)      отпущена в этом кадре
  input_mouse_btn(inp, button)           кнопка мыши (0,1,2)
  input_mouse_pressed(inp, button)       нажата в этом кадре
  input_mouse_pos(inp)                   → Vec2

7. МОДУЛЬ: physik.h
=========================================================================

Физический мир использует PBD (Position Based Dynamics), Verlet-интеграцию
и пространственный хеш для O(n log n) коллизий.

СОЗДАНИЕ:
  PhysicsWorld* physics_world_create(bounds_rect, time_step)
  void physics_world_destroy(world)
  void physics_world_reset(world)

ЧАСТИЦЫ (Particle):
  particle_create(world, pos, mass, radius, type) → Particle*
  particle_destroy(world, p)
  particle_apply_force(p, force_vec2)
  particle_apply_impulse(p, impulse_vec2)
  particle_apply_force_at(p, force, point)  — с угловым компонентом
  particle_set_position(p, pos)             — телепорт
  particle_set_layers(p, layer, mask)
  particle_set_lifetime(p, seconds)         — -1 = бесконечно

Типы частиц (ParticleType):
  PARTICLE_TYPE_NORMAL, STATIC, WATER, SAND, GAS, CLOTH,
  SOFT_BODY, RIGID, PROJECTILE, TRIGGER

Слои коллизий:
  LAYER_DEFAULT, LAYER_PLAYER, LAYER_ENEMY, LAYER_PROJECTILE,
  LAYER_TRIGGER, LAYER_TERRAIN, LAYER_ALL

Поля Particle:
  p->position, p->velocity, p->force
  p->mass, p->radius, p->friction, p->restitution, p->damping

13. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
=========================================================================

Q: Почему экран маленький (320×200)?
A: Движок использует пиксельный буфер для ретро-стиля.
   Он масштабируется до размера окна автоматически.
   Чтобы изменить разрешение: добавьте в cmp.bat перед компиляцией
   -DPB_W=640 -DPB_H=360 (или любые другие размеры).

Q: Как добавить свой звук?
A: Только WAV формат. Используйте audio_load() или audio.load() из Lua.

Q: Как установить SDL2.dll?
A: Скачайте SDL2-2.x.x-win32-x64.zip с github.com/libsdl-org/SDL/releases
   и положите SDL2.dll рядом с game.exe.

Q: Как использовать мировые координаты?
A: Мировые координаты = пиксельные координаты в буфере 320×200.
   Камера смещает/масштабирует вид. renderer_screen_to_world() конвертирует
   координаты мыши в мировые.

Q: Как сделать горячую перезагрузку Lua?
A: scripts_watch(sm, idx, true) + scripts_check_watches(sm, dt) каждый кадр.

Q: Максимум объектов в физическом мире?
A: По умолчанию не ограничен (динамический массив).
   HitboxManager: до 1024 хитбоксов (HBM_MAX).
   Lights: до 32 (MAX_LIGHTS).
   Force fields: до 16. Trigger zones: до 16.
